Privacy Policy

Last updated 15th of October 2026

This privacy policy applies to the Discord bot kafkaBot#9502 (application ID 1238981186035122257).

What data is stored

kafkaBot only stores the data its features need to work. This data is stored in a database and is linked to Discord IDs, not to real names or contact details.

  • Server settings: server ID and the channels, roles, messages and options configured with admin commands (welcome/goodbye, notifications, trivia, auto-role, reaction roles, auto-reactor, logging, store, confessions, AutoMod and daily quotes).
  • Leveling: your user ID, server ID, XP and level.
  • Economy: your user ID, server ID, rice grain balance, daily streak, last daily collection and your daily reminder time, if you set one.
  • Trivia: your user ID and your attempts on each daily trivia question.
  • Moderation: for warned users, the user ID, username and warning reasons; for temporary bans, the user ID and ban expiry time.
  • Quotes: when someone saves a message as a quote, the message content, its author's name and user ID, the date, and who added it.
  • Cooldowns: your user ID and command name, deleted automatically when the cooldown ends.

What is not stored

  • Confessions are posted to the configured channel without your name and are not saved by kafkaBot.
  • Deleted and edited message logs are posted to the server's chosen log channel and are not saved by kafkaBot.
  • Message content is read to give XP, auto-react and run AutoMod, but it is not saved, except for quotes as described above.

Data shared with others

  • Bug reports (/bug-report) and feedback (/feedback) are sent to a private channel for the developer, together with your Discord username, user ID and server. Bug reports may also be posted as an issue on the public kafkaBot GitHub repository, but only with the text you entered, not your username, user ID or server.
  • Game stats commands send the player name you enter to the relevant service: Riot Games, HenrikDev (Valorant) or osu!.
  • Notifications look up channels on YouTube and Twitch.
  • Logs: command usage (command name and server) and errors are logged for debugging and are visible only to the developer.

kafkaBot does not sell your data or use it for advertising.

Keeping and removing data

Data is kept until it is removed. Data for servers kafkaBot is no longer in, and for channels that no longer exist, is cleaned up periodically. Server admins can remove most server data with the matching disable or reset commands (for example /xp-reset, /clearwarn, /quote remove). To ask for your data to be deleted, or for any other privacy question, open an issue on GitHub or use /feedback.

When using Discord, Discord's Privacy Policy applies.
